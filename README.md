# Agentic-Linux-Incident-Responder

A hands-on agentic Linux operations lab using Pi, Superpowers, and Open Plan Annotator to investigate, remediate, and verify a systemd service incident with human approval and auditable evidence

## Workflow
Incident
→ Investigation
→ Evidence
→ Remediation Plan
→ Human Review
→ Approved Change
→ Verification
→ Incident Report

## Tools
- RHEL
- systemd
- Pi
- Superpowers
- Open Plan Annotator
- Git / GitHub
